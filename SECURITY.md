# Security reports

This is a beta project with root-level functionality. Only the latest beta is
actively maintained; there is no guaranteed response or patch timetable.

Use GitHub's **Security → Report a vulnerability** on this repository for a private
report. Include the affected version, reproduction steps and impact. Do not post
private signing keys, credentials or unredacted device backups in public issues.

The official APK certificate is documented in [docs/RELEASING.md](docs/RELEASING.md).
