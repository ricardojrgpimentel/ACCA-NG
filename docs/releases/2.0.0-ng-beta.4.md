# AccA-NG 2.0.0-ng-beta.4

Review scripts before running them, see their results clearly, and fix ACC command
lookup after module setup.

## Install or update

Download **AccA-NG-2.0.0-ng-beta.4.apk** below. Android 8.0+ and root are required.
Package: `com.accang.app`; version code: `44`.

The APK uses the same official signing identity as previous betas. Install it
over the existing release to retain app data. Debug builds install separately.

## Changes since beta.3

- Tapping a script opens its description and command. Execution starts only when
  Run is pressed, and repeated presses are blocked while it is running.
- Show output and error messages below the command, with the exit code and a
  Close action after completion. Empty output is explicitly identified.
- Remove the silent-run menu item and swipe execution shortcuts.
- Keep execution and result state across screen rotation, and handle shell
  exceptions as results instead of leaving the dialog loading.
- Run multiline commands, pipelines and shell builtins inside a bounded child
  shell. Include ACC runtime directories in its PATH so `acca` and `acc` work
  even when the module commands are not mounted into `/system/bin` yet.
- Identify development builds as **AccA-NG Debug**, with an orange launcher
  background and a **DBG** badge, including themed monochrome icons.

New script-dialog text is available in English and Portuguese (Portugal); other
languages use the English fallback for these additions.

## Included engine and source

The bundled engine remains **ACC-NG v1.0.3-ng** (based on ACC v2023.10.16),
with **DJS v2021.12.14**. Neither bundled archive changed in this release.

See the [validation record](https://github.com/ricardojrgpimentel/ACCA-NG/blob/v2.0.0-ng-beta.4/docs/releases/validation-2.0.0-ng-beta.4.md)

compatibility, complete charging cycles and physical thermal protection remain
outside this release's validation. This remains a prerelease.
