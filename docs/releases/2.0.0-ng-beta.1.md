# AccA-NG 2.0.0-ng-beta.1

First public beta of the independent AccA fork, with a refreshed interface,
modern Android compatibility and the ACC-NG charging engine.

## Install

Download **AccA-NG-2.0.0-ng-beta.1.apk** below. Android 8.0+ and root are required.
Package: `com.accang.app`; version code: `41`.

This installs separately from original AccA and debug builds. Profiles are not
migrated automatically. The ACC-NG setup screen asks before installing the engine;
it replaces an existing `acc` module, preserving configuration and creating backups.
Avoid using two frontends to control the same engine.

## Included

- ACC-NG v1.0.3-ng, based on ACC v2023.10.16, and DJS v2021.12.14.
- Charging profiles, diagnostics and charger-disconnected current calibration.
- Bounded root command timeouts, configuration readback and clearer setup errors.
- Current/voltage unit fixes and English/Portuguese engine notifications.
- Restored DJS source selection in the shared module installer for fresh installs.
- A dedicated release signing identity, build checks and public source provenance.

## Validation

67 release unit tests passed; lint has no errors (existing warnings remain).
APK signature and alignment were verified. Installation and same-version
replacement succeeded on Samsung SM-G975F. This does not establish compatibility
with other kernels or a complete charging-cycle test of the release frontend.

## Beta limitations

Physical validation currently covers a Samsung SM-G975F/kernel combination, not
all devices. Boot persistence, other kernels, a complete normal notification cycle
and physical thermal protection testing remain unverified. DJS installer selection
has regression tests; a fresh physical DJS install has not been validated for this
release. See the repository validation record for details.

Charging controls depend on the device kernel. Verify pause/resume behaviour on
your own device. The software is provided without warranty under GPL-3.0-or-later.
