# AccA-NG 2.0.0-ng-beta.8

Version code **48**; bundles [ACC-NG v1.0.9-ng/202610129](https://github.com/ricardojrgpimentel/ACC-NG/releases/tag/v1.0.9-ng). Fixes automatic current-polarity calibration after unplug: confirmed absent input skips unpowered ON retries, pending ON verification stops promptly, and unknown OEM input pauses still allow resume. API 1/schema 202310160, profiles and protection settings are retained.

## Install/update

Install **AccA-NG-2.0.0-ng-beta.8.apk** over the previous official AccA-NG app. Package `com.accang.app` and the established signing certificate are unchanged. Keep app data to retain profiles and preferences. Only the APK is needed; `SHA256SUMS`, the public certificate and `signature-verification.txt` support independent verification. For standalone module installation, use the matching engine release's ZIP.

## Validation and scope

- **119 app tests per debug/release**, both lints/builds, established APK signature and 16 KiB ZIP alignment passed. App main CI passed.
- Engine suite: **144 Android passed; 142 host passed plus two Android-only skips**, with Linux/macOS main CI green. The signed APK contains the exact reproduced engine archive.
- Final signed beta.8/module update on Samsung SM-G975F/Magisk preserved all current official/debug database rows and preferences, original config and all **31 runtime hashes**. The final physical cable trial learned negative polarity within **30 seconds** and resumed actual charging after reconnect. Configuration and last-good were restored byte for byte; one ready daemon and matching lock were verified.
- Earlier I6 clean installation, direct v1.0.3-ng on-disk upgrade, locked boot, capacity pause/resume, rollback/reinstall and SIOP-under-load trials retain their own source identities in the record.

This is a **prerelease**, with recorded physical scope on the Samsung/Magisk path. Successful writable current/voltage limits, independent OEM-policy behavior, other OEM devices and physical KSU/APatch still need suitable hardware. The full R7 goal remains incomplete. New optional R6 features remain outside this release; the automatic engine update channel is unchanged.
