# AccA-NG 2.0.0-ng-beta.7

Code 47; ACC-NG v1.0.8-ng (202610118), engine source
ea5972f5d95e08ba9b98ac67c83ef375121aad72. API 1/schema 202310160 and profiles retained.

- OEM sensor source/scale and shared incoming-power detection, including Samsung input pauses.
- Bounded switch tests with exact restoration/cancellation, limited recovery and thermal/capacity/cooldown protection.
- Atomic config/import/reset/script removal, backup recovery and daily schedules.
- Boot readiness, safe installation/download/rollback and bounded diagnostics.
- App readiness/fault diagnostics, literal arguments and verified test-worker cleanup.

133 engine cases (131 host plus two Android-only; 133 Android), 119 app tests per
variant, builds/lint and established signing certificate verified. Samsung
upgrade, switch, capacity pause/resume, rollback/reinstall, locked reboot and
APK updates passed; original config/database/preferences and DJS retained in
the recorded trials. General use on Samsung was also reported working well by
the user. The encrypted official-app data was rechecked after unlock on
12 October: all database rows and preferences matched the pre-PIN backup. Another signed update
retained both apps' database rows; the official app cleared only the stale active
profile selection when it read the current custom engine settings. Live clean
module installation and restoration of the existing installation also passed.

This is a prerelease with physical validation on Samsung SM-G975F / Magisk.
Successful current/voltage limiting on writable kernels, KSU/APatch, other OEM,
and physical USB unplug/replug on this version require their own tests. Samsung
SIOP write/readback/restoration passed; its electrical effect under load is not certified. New optional R6 idle_apps, Encore and
percentage-current features remain outside this release.

Install **AccA-NG-2.0.0-ng-beta.7.apk**. Only the APK is needed; SHA256SUMS,
the public certificate and signature-verification.txt allow download verification.
The package and signing certificate are unchanged, allowing an update over
previous official AccA-NG releases without clearing app data.

The APK bundles [ACC-NG v1.0.8-ng](https://github.com/ricardojrgpimentel/ACC-NG/releases/tag/v1.0.8-ng).
For standalone Magisk installation, use that release's module ZIP. The existing
automatic-update metadata is not promoted by this prerelease.
See [the validation record](https://github.com/ricardojrgpimentel/ACCA-NG/blob/v2.0.0-ng-beta.7/docs/acc-ng-validation.md#i6-joint-core-candidate--2026-10-11)
for evidence and remaining tests.
