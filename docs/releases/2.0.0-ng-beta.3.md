# AccA-NG 2.0.0-ng-beta.3

Updated translations and immediate language switching, plus the profile fixes
from the locally tested beta.2 candidate.

## Install or update

Download **AccA-NG-2.0.0-ng-beta.3.apk** below. Android 8.0+ and root are required.
Package: `com.accang.app`; version code: `43`.

The APK uses the same official signing identity as beta.1 and the local beta.2
candidate. Install it over either version to retain app data. Original AccA and
debug builds have different package IDs and install separately.

## Changes since beta.1

- Translate 230 new interface strings across all 21 existing locales, with
  expanded Portuguese coverage. Older untranslated strings still fall back to
  English in some languages; AI-assisted translations may need native review.
- Apply language changes immediately through AndroidX activity recreation, save
  the selection and remove the obsolete manual-restart message.
- Correct Greek and Indonesian language codes, migrate saved choices and update
  localized widget and quick-settings labels.
- Include all languages for offline switching, including future App Bundle builds.
- Fix modern ACC-NG profile temperature commands and readback while preserving
  legacy profiles; show resume temperature in degrees Celsius.
- Add Copy details to command results and validate new translation resources in CI.

## Included engine and source

The bundled engine remains **ACC-NG v1.0.3-ng** (based on ACC v2023.10.16),
with **DJS v2021.12.14**. Neither bundled archive changed in this release.

## Validation and beta limitations

77 release unit tests passed, lint completed without errors, and translation
checks, APK signature and ZIP alignment passed. See the
[validation record](https://github.com/ricardojrgpimentel/ACCA-NG/blob/v2.0.0-ng-beta.3/docs/releases/validation-2.0.0-ng-beta.3.md).

The final signed APK was installed over beta.2 on a Samsung SM-G975F, preserving
the active profile. Switching from Polish to Portuguese immediately updated the
settings screen without restarting the app process. The previous beta.2
candidate's profile fixes were also tested on this device. Other Android versions,
kernel compatibility, complete charging cycles and physical thermal protection
remain outside this release's validation. This remains a prerelease.
